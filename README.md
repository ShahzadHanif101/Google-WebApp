How to set up:

1. In your Google Apps Script project, click the + button next to Files
2. Select HTML and name it Index
3. Paste the HTML code above into the new file
4. Replace your Code.gs with the first code block (the one with doGet())
5. Save and deploy the project


How to Use:

1. Deploy this code as a web app in Google Apps Script
2. Set Permissions when prompted (needs access to your spreadsheet)
3. Open the deployed URL
